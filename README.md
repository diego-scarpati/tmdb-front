# The Movie Database

A client-side React application for discovering movies and TV series.

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm start
```

Vite prints the local URL in the terminal (usually <http://localhost:5173>).

## Production

Create and preview a production build:

```sh
npm run build
npm run preview
```

The production files are written to `dist/`. Configure the static host to serve
`index.html` for application routes so React Router can handle direct links.
